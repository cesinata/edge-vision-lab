# Illustration style: Option A, Datasheet

Public-safe. This replaces the earlier "Pastel Paper Mono" style. It tells whoever draws or regenerates the website illustrations and the README figures what to follow.

## Look

Technical-datasheet: white page, deep navy ink, thin grid-paper panels, fine line drawings, and a single yellow highlight. Figures are numbered like a datasheet ("Fig. 0", "Fig. 1", and so on). Drawings are original; nothing is traced from a vendor figure, and no vendor logo, badge or brand-styled wordmark is used. The colours are inspired by embedded-tools documentation and do not copy any vendor palette beyond the tokens below.

## Tokens

| Token | Light | Dark | Use |
| --- | --- | --- | --- |
| bg | #FFFFFF | #0B1A2E | page |
| panel | #F7F9FC | #10243F | grid-paper panels |
| grid | #E3E9F2 | #1A3354 | 24 px grid lines on panels |
| ink | #03234B | #EAF2FB | text, primary lines, primary button |
| ink-2 | #2A4365 | #C9D8EA | body text |
| muted | #3C5677 | #A8BCD6 | labels, captions |
| rule | #C6D2E1 | #2B4A70 | dividers, inner rules |
| line | #03234B | #8FD3F4 | illustration strokes |
| mark | #FFD200 | #FFD200 | highlight fill only |
| on-ink | #FFFFFF | #0B1A2E | text on the primary button |

Yellow is only ever a fill, never text and never the only signal (a label, number or pattern always accompanies it). The only text on yellow is the dark ink `#03234B`. Text and background pairs reach 4.5:1 (3:1 for large text and for non-text strokes). The contrast checks are scripts: `scripts/check_contrast.py` for the website tokens and `scripts/make_figures.py` for the README figures; both write their results to `results/`.

## Type and shape

- Website: IBM Plex Sans (400, 500, 600, 700) for text and IBM Plex Mono (400, 500, 600) for labels, numbers and captions, self-hosted from the `@fontsource` packages (SIL Open Font Licence 1.1). No runtime font service.
- README figures: a system monospace stack, `ui-monospace, "SF Mono", Menlo, Consolas, monospace`, because SVGs shown on GitHub cannot load web fonts. Body text in figures is at least 12 px.
- Radius 4 to 6 px. Borders 1.5 px in ink on cards, 1 px in rule inside them.

## Drawing rules

Fine line: 1.5 px stroke (1.25 px for small details), round caps and joins, strokes follow the theme (`currentColor`), no fills except the yellow highlight and the background colour used to mask lines. Each drawing is a small component under `web/src/illustrations/` and stays under 6 KB. Every informative drawing has a `<title>` or an `aria-label`; purely decorative ones are `aria-hidden`. Do not draw solar panels or solar farms anywhere; power is shown as a battery.

## The README figures

All in `docs/img/` as `<name>.svg` (light) and `<name>-dark.svg`, shown with `<picture>` and `prefers-color-scheme`, generated by `python scripts/make_figures.py`:

1. **pipeline**: six numbered cells with line icons, data to firmware.
2. **split-by-scene**: six scenes of four frames beside a random split that leaks. Pattern and label as well as colour.
3. **board-data-path**: an original generic board with a strip saying it is not measured on hardware.
4. **results**: confusion matrix and float32 versus partly int8, drawn from `results/eval_torch.json` and `bench/results.json`; "not run yet" where a file is missing.
5. The firmware state diagram is Mermaid in the README (GitHub draws and themes it), generated by `guardian_cli --mermaid`.

## What never goes in a figure

Dataset frames or crops, vendor artwork or logos, other people's brands, employer or project names, invented numbers, solar panels, and claims about speed, accuracy or device support that the repository has not measured.
